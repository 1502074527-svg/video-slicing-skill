# 领域化定制指南

> 这套 Skill 的骨架是领域无关的，**领域特定内容只有两样**：词表 和 校对 Prompt。
> 换领域 = 换这两份文件，骨架代码一行不动。

## 两份领域文件

| 文件 | 作用 | 格式 |
|---|---|---|
| **词表**（`references/lexicons/<你的领域>.txt`） | 确定性替换规则 + 热词列表 | 纯文本，`误写 => 正写` 一行一条 |
| **校对 Prompt**（`references/prompts/proofreader-<你的领域>.md`） | LLM 校对员的人设与领域知识 | Markdown，可含经典原文引用 |

## 词表怎么写

### 基础格式

```
# 注释用 # 开头
误写 => 正写
人禽之变 => 人禽之辨
侧然 => 恻然
```

### 三种条目

1. **术语替换**（`误写 => 正写`）：确定性的，替换零风险
2. **热词**（只写正词，无 `=>`）：供 ASR / LLM 参考，不直接替换
3. **风险词**（注释里标注 `# 风险`）：容易误改的词，提醒人工注意

### 起草自己领域的词表

**方法 1：从 PPT/讲义提取**（推荐）

把 PPT/讲义文本喂给 LLM，问：

> 「这是【某领域】课程的讲义。请提取 30-50 个高频专业术语，以及每个术语在 ASR 中最可能被听成的错误写法。输出格式：`误写 => 正写`」

**方法 2：从初版转写稿反向归纳**

先空跑一遍转写，把明显听错的术语人工归纳成词表，然后跑第二轮。

**方法 3：参考已有领域词表**

`references/lexicons/confucian.txt` 是儒学完整示例（94 条），可以当模板。

### 词表大小参考

| 领域 | 建议条目数 | 备注 |
|---|---|---|
| 高度专业化（儒学/医学/法律） | 50-150 | 术语密度高 |
| 一般技术课程 | 20-50 | 够用 |
| 通用讲座 | 0-20 | 几乎不需要 |

## 校对 Prompt 怎么写

### 结构

参考 `references/prompts/proofreader-template.md` 的骨架：

```markdown
# 角色设定
你是【某领域】课程录音的听打校对员……

# 任务约束
只允许两类修改：
1) 同音/近音错字
2) 补标点

# 硬性禁止
- 不删语气词
- 不改写不润色
- 不确定就低置信

# 领域知识
（这里塞你领域的术语表、常见错法、经典原文片段）

# 输出格式
JSON 数组，每项 {i, text, changed, reason, confidence}
```

### 关键点

- **领域知识要具体**：不要写「小心专业术语」，要写「『人禽之辨』不是『人禽之变』」
- **给经典原文**：如果领域有权威文本（儒学有四书、法律有法条、医学有指南），把关键片段塞进 Prompt
- **给已知错法**：历次实战中总结的错法清单最有价值

## 沉淀机制（越用越准的秘密）

### 闭环

```
第 1 轮：词表 20 条 → ASR 错 30 处 → LLM 抓 25 处 → 人审确认 20 处
              ↓ 沉淀
第 2 轮：词表 40 条 → ASR 错 15 处 → LLM 抓 12 处 → 人审确认 10 处
              ↓ 沉淀
第 3 轮：词表 60 条 → ASR 错 5 处 → LLM 全抓到
              ↓
        几乎不用人审
```

### 工具

`scripts/consolidate_lexicon.py` 是闭环的关键：

```bash
# 默认只读：列出建议新增哪些，不写文件
python3 scripts/consolidate_lexicon.py 校对建议.tsv 术语替换表.txt

# 用户逐条确认后，显式加 --write 才真写进词表
python3 scripts/consolidate_lexicon.py 校对建议.tsv 术语替换表.txt --write
```

**过滤规则**（自动）：
- 只回写「改动=是 且 置信度 ≥0.9 且 未命中现有词表」的
- 跨度 >2 字的（整句重写）不回写
- 已在词表里的不重复

**人工把关**：默认只读，不加 `--write` 永不落盘——这是最后的防线。

## 跨领域复用检查清单

要把这套 Skill 用到新领域，按顺序检查：

- [ ] 写一份 `references/lexicons/<新领域>.txt`（至少 20 条）
- [ ] 写一份 `references/prompts/proofreader-<新领域>.md`（基于 template 改）
- [ ] 如果领域有权威文本，准备参考原文 TXT 放进 `references/lexicons/<新领域>-corpus/`
- [ ] 先跑一遍转写 + 校对，确认术语准确率 >90%
- [ ] 不满意就补词表，满意就沉淀回写
- [ ] 三轮下来词表应该稳定了
