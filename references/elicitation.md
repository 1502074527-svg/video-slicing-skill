# 引导话术集（Elicitation）

> 本文件是 Agent 在 7 个关键决策点向用户提问的**话术模板**。
> 标 ★ 的是**必停节点**——没问用户就往下跑等于违规。
> 标 ★★ 的是**双停节点**——跑前停一次、跑后停一次。

**使用原则**：
- 话术是参考，可按语境微调，但**选项数量、默认推荐、信息要素不能少**
- 永远给推荐项并说明理由，但不替用户选
- 用户说「随便」「你定吧」也要列出选项让他确认——这不是麻烦，是责任划分

---

## ★ 1. 任务摸底

**时机**：用户第一次提出切片需求时

**必问信息**：领域、时长、素材完备度

**话术**：

```
开工前我需要先了解 3 件事，能帮我确认下吗？

1. 这段视频是什么领域的？
   - 儒学/国学（有现成词表与 Prompt，推荐）
   - 医学/法律/编程/其他技术领域（需要起草词表）
   - 通用讲座（无明显专业术语）

2. 视频时长大约多少？
   - < 30 分钟（可跳过切点，直接做整段字幕）
   - 30 分钟 - 2 小时（标准流程）
   - > 2 小时（建议先分段再处理）

3. 有没有现成的领域资料？
   - 有术语表/热词表（告诉我路径）
   - 有 PPT/讲义/参考书籍（我可以用来起草词表）
   - 都没有（我会从视频内容自动提取高频术语给你审）
```

## ★ 2. 选 ASR 方案

**时机**：摸底完成后、开始转写前

**核心权衡**：字级时间戳 vs 自带标点 vs 成本

**话术**：

```
转写方案有 3 个，精度参考值如下（本机一次实测、样本有限，只用于比较量级）：

| 方案 | CER | 字级时间戳 | 自带标点 | 成本 | 音频去哪 | 推荐场景 |
|---|---|---|---|---|---|---|
| A. 剪映 ASR（VideoCaptioner 调用） | 15.2% | ✅ | ❌ | 免费 | ⚠️ 上传剪映云端 | 【主推】字级是时间轴金标准 |
| B. Whisper.cpp large-v3 + 领域 Prompt | 17.7% | ❌ | ✅ | 免费（本地跑） | ✅ 不出本机 | 抓漏字对照 |
| C. 火山方舟豆包语音 | ~15% | ✅ | ✅ | 约 1-5 元/小时 | ⚠️ 上传火山云端 | 商业项目、热词强需求 |

隐私要提前说清：只有 B 全程离线；A 走剪映非官方逆向接口（可能随时失效），
C 走火山官方 API。这段课程涉密/未公开/有版权限制吗？

推荐组合：
- 单方案：选 A（字级优先）
- 双通道：A 主力 + B 对照抓漏字（精度最稳）
- 商业：C（支持热词注入，省后处理）
- 不可外传：只能选 B（但 B 无字级时间戳，后续要人工校准）

你选哪个？
```

**不允许**：默认用 A 不问用户——用户可能有隐私/预算/网络限制。

## ★ 3. 领域词表定制

**时机**：ASR 选定后、跑转写前

**话术**：

```
接下来要准备你领域的词表（术语替换表 + 热词表）。

我看到你的领域是【<领域>】，目前的状态是：
- [ ] 你有现成词表 → 告诉我路径，我直接用
- [ ] 没有词表，但有 PPT/讲义/参考书 → 给我路径，我帮你起草 20-50 条
- [ ] 什么都没有 → 我先空跑转写，从初稿里提取高频术语给你审

参考：
- 空白模板在 references/lexicons/_template.txt
- 儒学完整示例在 references/lexicons/confucian.txt（94 条替换规则 + 热词表）

你想走哪条路？
```

## ★★ 4. LLM 校对（双停）

### 4.1 跑前确认 Prompt

**时机**：跑 `proofread_llm.py review` 前

**话术**：

```
校对 Prompt 准备好了，你确认下用哪一份：

- [ ] references/prompts/proofreader-confucian.md（儒学版，含《四书章句集注》知识库）
- [ ] references/prompts/proofreader-template.md（通用模板，需要自己补领域知识）
- [ ] 你自己提供的 Prompt 文件 → 告诉我路径

校对员人设要点：
- 只改「同音/近音错字」+「补标点」，不改写不润色
- 不确定的给低置信度，依据栏写疑问
- 禁止编造、禁止删语气词（后续有专门清理环节）

确认用哪份？
```

### 4.2 跑后强制人工审

**时机**：TSV 生成后，**任何情况下都不许跳过**

**话术**：

```
✅ 校对建议已生成：<路径>/校对建议.tsv

统计：
- 共 <N> 句
- 建议改动 <M> 句
- 高置信（≥0.9）<K> 句

⚠️ 请你人工审查 TSV 后，再让我合入。
   建议用 Excel / VSCode / 任何表格工具打开，
   重点看「改动=是」且「置信度 ≥0.9」的行，
   不确定的把置信度改低，我会跳过。

审查完告诉我「可以合入」或「跳过以下行号：...」。
```

## ★ 5. 沉淀回写

**时机**：校对合入完成后

**话术**：

```
本轮校对发现了 <K> 个「建议改动但未命中现有词表」的术语对，可能是新术语。

我先默认只读跑一遍，给你看清单（不会碰词表文件）：

  $ python3 scripts/consolidate_lexicon.py 校对建议.tsv 术语替换表.txt

[展示清单，例如]
  1. 侧然 → 恻然        (出现 3 次，平均置信 0.92)
  2. 人禽之变 → 人禽之辨 (出现 2 次，平均置信 0.95)
  3. 结囊 → 截然        (出现 1 次，置信 0.88)

请确认哪些要写进词表：
- 全部写进
- 只写编号 <X, Y, Z>
- 都不写（保留原样，下轮还会再提）

你选定之后，我加 --write 真写——未经你确认我不会落盘。

写进后下次转写同领域内容会自动应用，越用越准。
```

## ★ 6. 选断句模式

**时机**：字幕构建前

**话术**：

```
字幕断句有 3 种电影级模式，对应不同平台节奏：

| 模式 | 断句位置 | 单条时长中位数 | 节奏感 | 适用 |
|---|---|---|---|---|
| sentence 整句 | 。？！ | ~5s | 舒缓 | B 站/学术讲座/课程长视频 |
| clause 半句 | ，、；：。？！ | ~2.5s | 明快 | 视频号/小红书/知识短视频 |
| fragment 碎句 | 所有标点 + 长句强断 | ~1.5s | 紧凑 | 抖音/快手/Shorts |

你的目标平台是？或者要混合（先 clause 出一版看看效果）？

补充：字级时间戳是精确到字的，所以三种模式都不会腰斩语义，
只是节奏不同。可以随时换一种模式重新生成。
```

## ★ 7. 切点确认

**时机**：切点表生成后

**话术**：

```
✅ 切点表已生成：<路径>/切点表.md

共提议 <N> 个切片，每个 30 秒 - 5 分钟，内容完整、逻辑连贯。

请人工审一遍切点表：
- 看每段起止是否合理（没有截断完整语句）
- 看内容是否值得单独发
- 删除不满意的行，或改起止时间

确认后我用 generate_slices.py 批量切片（重编码精切，字幕自动时间归零），
切完再用 verify_slices.py 核验时长与切点；有异常我会停下来告诉你。
如果你已经选了片段范围
（比如告诉我「第 2 段不要，第 5 段改成 10:23 - 12:45」），
我直接按你的改。
```

## 反引导（不要问的）

以下问题**不要问用户**，按规则自己判断：

- 字幕文件命名（按 SOP 约定）
- 临时文件放哪（用 `mktemp -d`）
- Python 依赖安装（自检脚本会提示）
- 中间产物格式（SRT/TSV 固定）
- 是否保存日志（永远保存，可追溯）

问这些只会打断节奏。**引导的价值在关键决策，不在琐事。**
