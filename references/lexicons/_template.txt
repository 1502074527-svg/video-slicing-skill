# 领域词表模板
#
# 用法：
#   1. 复制本文件，重命名为 <你的领域>.txt
#   2. 按下述三类条目填充
#   3. 把路径告诉 Agent，Agent 会用它做术语替换与 LLM 校对参考
#
# 条目分类：
#   ① 术语替换（误写 => 正写）：确定性的，替换零风险
#   ② 热词（只写正词）：供 ASR / LLM 参考，不直接替换
#   ③ 风险词（注释 # 风险）：容易误改的词，提醒人工注意
#
# ────────────────────────────────────────────────
# ① 术语替换（误写 => 正写）
# ────────────────────────────────────────────────
#
# 示例（删掉这些示例，填你自己的）：
# 误写词A => 正确词A
# 误写词B => 正确词B
# 人名错写 => 人名正写
#
# ────────────────────────────────────────────────
# ② 热词（只写正词，无 =>）
# ────────────────────────────────────────────────
#
# 示例（删掉这些示例，填你自己的）：
# 高频专业术语1
# 高频专业术语2
# 经典篇名
# 重要人名
#
# ────────────────────────────────────────────────
# ③ 风险词（在注释里标注，提醒人工）
# ────────────────────────────────────────────────
#
# 示例：
# 正词C   # 风险：与同音词「另一词」易混，靠上下文区分
#
