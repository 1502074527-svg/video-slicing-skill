# 字幕断句三模式（电影级）

> 同一份字级时间戳 + 同一份文本，可以产出三种节奏的字幕。
> 选哪种取决于你的目标平台和观众耐心。

## 三种模式对比

### `sentence` 整句模式

**断句位置**：只在 `。 ？ ！` 断句
**单条时长**：中位 ~5 秒
**节奏**：舒缓，让观众慢慢看

**适用**：B 站、学术讲座、系统课程

**效果示意**：

```
[00:00:01.200 --> 00:00:06.800]
孟子说，人之所以异于禽兽者几希，庶民去之，君子存之。

[00:00:07.100 --> 00:00:12.300]
舜明于庶物，察于人伦，由仁义行，非行仁义也。
```

### `clause` 半句模式

**断句位置**：`， 、 ； ： 。 ？ ！` 都断
**单条时长**：中位 ~2.5 秒
**节奏**：明快，观众不会觉得累

**适用**：视频号、小红书、知识类短视频

**效果示意**：

```
[00:00:01.200 --> 00:00:03.500]
孟子说，

[00:00:03.500 --> 00:00:06.800]
人之所以异于禽兽者几希，

[00:00:07.100 --> 00:00:09.000]
庶民去之，

[00:00:09.000 --> 00:00:10.500]
君子存之。
```

### `fragment` 碎句模式

**断句位置**：所有标点 + 长句强制在固定字数处断
**单条时长**：中位 ~1.5 秒
**节奏**：紧凑，几乎一个词一屏

**适用**：抖音、快手、YouTube Shorts

**效果示意**：

```
[00:00:01.200 --> 00:00:02.300]
孟子说，

[00:00:02.300 --> 00:00:03.500]
人之所以异于禽兽者

[00:00:03.500 --> 00:00:04.200]
几希，

[00:00:04.200 --> 00:00:05.500]
庶民去之，

[00:00:05.500 --> 00:00:06.800]
君子存之。
```

## 使用

```bash
python3 scripts/build_subtitles.py 字级.srt 文本.srt 输出.srt \
  --mode <sentence|clause|fragment> \
  --fps 30
```

## 实现要点

三种模式共用一套字级对齐算法，只在「分句规则」上不同：

| 模式 | 分句规则 | 强断阈值 |
|---|---|---|
| `sentence` | 仅在 。？！ 后断 | **不按字数强断**；超长只告警，建议补标点或换 clause |
| `clause` | 在 ，、；：。？！ 后都断 | 单条 >20 字在就近标点断 |
| `fragment` | 所有标点后都断 + 单条 >10 字强断 | 强断在最近的字级边界 |

**帧吸附**：所有时间戳都吸附到最近的 30fps 帧边界（可配），避免字幕闪动。

**跨静音不并条**：相邻两字间隔 ≥1.2s 视为静音，强制断条——避免字幕"挂着不动"17.7 秒的尴尬。

**不回并跨句**：已以 。？！ 结尾的块不会被回并进下一块——整句模式不会因为下一块太短就合并成超长条。

## 选哪种？

| 你的目的 | 推荐模式 |
|---|---|
| 学术严谨、让观众读完整论证 | `sentence` |
| 平衡信息密度与可读性 | `clause` ⭐ 默认推荐 |
| 抖音爆款、追求节奏感 | `fragment` |
| 同一内容发多平台 | 每种各出一版 |

**混合策略**：主平台用 `clause` 出一版，发布后看数据再决定是否要 `fragment` 出短平快版。

## 反模式（不要这么做）

- ❌ **按字数等比拆**：「15 字一条」无视语义，必然腰斩
- ❌ **按标点机械拆不看时长**：如果 3 个字就一条，观众看不清
- ❌ **跨静音并条**：讲者停顿 5 秒想下一句，字幕还挂着上一句，极违和
- ❌ **混用多种规则**：同一片段里一会儿 sentence 一会儿 clause，观众会乱

选定一种模式就**全片统一**。
