# 字幕断句四模式（电影级）

> 同一份字级时间戳 + 同一份文本，可以产出四种节奏的字幕。
> 选哪种取决于你的目标平台和观众耐心。

## 四种模式对比

### `sentence` 整句模式

**断句位置**：只在 `。 ？ ！` 断句
**单条时长**：中位 ~5 秒
**节奏**：舒缓，让观众慢慢看

**适用**：B 站、学术讲座、系统课程

**效果示意**：

```
[00:00:01.200 --> 00:00:06.800]
孟子说，人之所以异于禽兽者几希，庶民去之，君子存之。

[00:00:07.100 --> 00:00:12.300]
舜明于庶物，察于人伦，由仁义行，非行仁义也。
```

### `semantic` 语义句模式（默认）

**断句位置**：句界 `。 ？ ！` 硬断；整句 ≤16 实字**不拆**，超长才在句内软标点（`，、；：`）处拆
**单条时长**：中位 ~4 秒（随素材与句长波动，介于 sentence 与 clause 之间）
**节奏**：一句话一幕，语义完整优先，长度只做兜底

**适用**：课程切片、知识口播、16:9 横屏交付

**与另外两种的区别**：
- 比 `sentence` 多一道「超 16 字才拆」的兜底，不会出现 30 字挤一幕
- 比 `clause` 少切软标点，不会把「上一句下半 + 下一句上半」拼成一幕

### `clause` 半句模式

**断句位置**：`， 、 ； ： 。 ？ ！` 都断
**单条时长**：中位 ~2.5 秒
**节奏**：明快，观众不会觉得累

**适用**：视频号、小红书、知识类短视频

**效果示意**：

```
[00:00:01.200 --> 00:00:03.500]
孟子说，

[00:00:03.500 --> 00:00:06.800]
人之所以异于禽兽者几希，

[00:00:07.100 --> 00:00:09.000]
庶民去之，

[00:00:09.000 --> 00:00:10.500]
君子存之。
```

### `fragment` 碎句模式

**断句位置**：所有标点 + 长句强制在固定字数处断
**单条时长**：中位 ~1.5 秒
**节奏**：紧凑，几乎一个词一屏

**适用**：抖音、快手、YouTube Shorts

**效果示意**：

```
[00:00:01.200 --> 00:00:02.300]
孟子说，

[00:00:02.300 --> 00:00:03.500]
人之所以异于禽兽者

[00:00:03.500 --> 00:00:04.200]
几希，

[00:00:04.200 --> 00:00:05.500]
庶民去之，

[00:00:05.500 --> 00:00:06.800]
君子存之。
```

## 使用

```bash
python3 scripts/build_subtitles.py 字级.srt 文本.srt 输出.srt \
  --mode <sentence|semantic|clause|fragment> \
  --fps 30 [--punct-mode course|film]

# 产出体检（建议每次交付前跑；上限与断句口径保持一致）
python3 scripts/build_subtitles.py check 输出.srt --max-chars 16 --max-cps 9
```

## 实现要点

四种模式共用一套字级对齐算法，只在「分句规则」上不同：

| 模式 | 分句规则 | 强断阈值（阅读字数） |
|---|---|---|
| `sentence` | 仅在 。？！ 后断 | **不按字数强断**；超长只告警，建议换 `semantic` |
| `semantic`（默认） | 仅在 。？！ 后成句；超长才在句内软标点拆 | 单条 >16 字在就近软标点/最长停顿处拆 |
| `clause` | 在 ，、；：。？！ 后都断 | 单条 >20 字在就近标点断 |
| `fragment` | 所有标点后都断 + 单条 >10 字强断 | 强断在最近的字级边界 |

**三条铁律**（`semantic` 模式必须同时满足）：
1. **禁止跨句拼接**：任何一幕的首字不能是上一句的尾巴，幕尾不能是下一句的开头
2. **单行铁律**：一幕只有一行，≤16 实字，装不下拆成下一幕，绝不折行
3. **禁止整秒切点**：切点落在字幕条间隙，不落在 cue 中间

**阅读字数口径**：判超长、算读速一律**只数实字，标点和空白不计**。
「儒家，讲义。」是 4 字，不是 6 字——按带标点的长度算会把上限吃掉三分之一。

**帧吸附**：所有时间戳都吸附到最近的 30fps 帧边界（可配），避免字幕闪动。

**跨静音不并条**：相邻两字间隔 ≥1.2s 视为静音，强制断条——避免字幕"挂着不动"17.7 秒的尴尬。

**不回并跨句**：已以 。？！ 结尾的块不会被回并进下一块——整句模式不会因为下一块太短就合并成超长条。

## 连接词不悬空（改切点，不改文字）

一幕的结尾不能挂在连接词上（「……因此」「……总之」「……就是」）。

**正确做法**：把这一刀的**切点前移**到连接词之前，让连接词成为下一幕的开头。字符时间戳不动，
所以文字与声音仍然逐字对齐。

**错误做法**（见过但不要用）：把连接词那两个字**挪到下一幕文本开头**。这样屏幕上写「就是它一方面」，
耳朵听到的是「总之，就是它一方面」——文字比声音早，等于人为造出音画不同步。
要挪的是**边界**，不是**文字**。

内置连接词表偏口语（那么、然后、就是、这个、那个、的话、因为、如果、比方…），
因为课程实录里挂得最多的就是这些。句末标点收尾的不算悬空。

**悬空黑名单（幕尾出现即判违规）**：

```
但是 然而 所以 因此 而且 并且 或者 还是 不过 可是 再说 另外
同时 其实 毕竟 总之 也就是说 换句话说
```

两种消解方式按管线能力选，**不要混用**：
- **有字级时间戳**（本工具链）：把切点前移到连接词之前，让连接词开下一幕
- **只有纯文本**（外部字幕文件）：把连接词向前合并进上一幕，不单独成行

## 产出体检（`check`）

```bash
python3 scripts/build_subtitles.py check 精确字幕.srt --max-chars 16 --max-cps 9
```

| 级别 | 检查项 | 说明 |
|---|---|---|
| ✗ 强制 | 两行及以上 | 单行铁律：超长拆成多幕，不折行 |
| ✗ 强制 | 纯标点卡 | 只剩 `，` `。` 这类卡等于空屏 |
| ✗ 强制 | 阅读字数超上限 | 默认 16 字；宽屏/大字可放宽到 20 |
| ✗ 强制 | 读速 > 9 字/秒 | 舒适区 3–6，9 是上限 |
| △ 建议 | 连接词悬空 | 切点能修则修，修不了（已是句末）只提示 |

✗ 任一条命中，退出码为 1，流水线应停下；△ 只提示，不阻断交付。

## 标点渲染：course / film

同一份时间轴，两套显示口径：

| 模式 | 句号 | 逗号/顿号/分号 | 问号/感叹号 | 书名号 | 引号 | 用途 |
|---|---|---|---|---|---|---|
| `course`（默认） | 保留 | 保留 | 保留 | 保留 | 保留 | 课程、讲座，标点帮助理解 |
| `film` | 删除 | 换成空格 | 保留 | 保留 | **删除** | 短视频、混剪，字幕只当提示 |

> 2026-11-02 起 `film` 口径**删除全部引号**（`「」『』“”‘’`）：单行 16 字上限下，一对引号占 2 个全角位；
> 引文边界改由断行与上下文识别。`course` 模式仍完整保留。

```bash
python3 scripts/build_subtitles.py 字级.srt 校对.srt 输出.srt --mode semantic --punct-mode film
```

## 选哪种？

| 你的目的 | 推荐模式 |
|---|---|
| 学术严谨、让观众读完整论证 | `sentence` |
| 语义完整 + 长度可控，课程/知识短视频 | `semantic` ⭐ 默认推荐 |
| 节奏明快、信息密度优先 | `clause` |
| 抖音爆款、追求节奏感 | `fragment` |
| 同一内容发多平台 | 每种各出一版 |

**混合策略**：主平台用 `semantic` 出一版，发布后看数据再决定是否要 `fragment` 出短平快版。
`clause` 与 `semantic` 不要在同一片段里混用——一个切软标点、一个不切，节奏会乱。

## 反模式（不要这么做）

- ❌ **按字数等比拆**：「15 字一条」无视语义，必然腰斩
- ❌ **按标点机械拆不看时长**：如果 3 个字就一条，观众看不清
- ❌ **跨静音并条**：讲者停顿 5 秒想下一句，字幕还挂着上一句，极违和
- ❌ **混用多种规则**：同一片段里一会儿 sentence 一会儿 clause，观众会乱
- ❌ **搬文字造同步**：为了不悬空，把连接词从上一幕挪到下一幕开头 → 文字比声音早，音画错位
- ❌ **比例分时间**：没有字级稿时按字数占比硬算每条起止 → 语速稍有不均就累积漂移
- ❌ **取消静音断条换「严格首尾相接」**：卡与卡紧贴无空隙，等于放弃停顿感知，长静音时字幕一直挂着
- ❌ **不吸附帧边界**：毫秒值直接落盘，烧进视频后逐帧闪动

选定一种模式就**全片统一**。
